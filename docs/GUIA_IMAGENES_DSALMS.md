# Guía de imágenes de D'Salms
Hay **65 espacios de imagen** registrados (9 con imagen provisional conceptual y 56 pendientes). Cada espacio está identificado en el HTML con un comentario que repite estos datos, y también se consulta dentro de la web en **Recursos visuales** (enlace en el pie de página).

## Cómo reemplazar o agregar una imagen (ejemplo: la misión)
1. Busca el código `DS-IMG-EMP-001` en esta guía.
2. Lee la escena y la medida (1200 × 800 px, 3:2).
3. Copia el prompt y genera la imagen en tu IA.
4. Exporta como **WebP** (o PNG/JPG).
5. Guárdala con el nombre exacto `empresa-mision-01.webp`.
6. Colócala en `img/empresa/`.
7. Abre la página Empresa y comprueba que la imagen aparece en la sección Misión.
8. Revisa el encuadre en el móvil.
9. Sube los cambios con GitHub Desktop (Commit y Push).
Si el espacio sigue mostrando «IMAGEN PENDIENTE», el nombre o la carpeta no coinciden: compáralos con la columna «Archivo exacto».

## Reglas de nombres
`<página>-<tema>-NN.webp` en minúsculas, sin tildes ni espacios. Las imágenes originales del proyecto (`img/identidad`, `img/aplicaciones`, `img/comunicacion`, etc.) no se renombraron.
