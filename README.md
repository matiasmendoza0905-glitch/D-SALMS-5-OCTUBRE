# D'Salms · «Viste tu esencia»
Sitio académico de moda cristiana contemporánea (Design Salms S.A.C., Pichanaqui, Junín). HTML, CSS y JavaScript sin dependencias, publicable en GitHub Pages.

## Páginas
Inicio · Empresa · Público objetivo · Identidad corporativa · Identidad visual · Imagen institucional · Aplicaciones · Productos · Comunicación · Plan de Comunicación · Auditoría de Imagen · Manual de identidad · Propuestas · Contacto. Además, `recursos-visuales/` (guía interna, enlazada en el pie).

## Abrir y publicar
- Local: doble clic en `index.html` (los enlaces incluyen `index.html`, así que funcionan sin servidor).
- GitHub Pages: copia todo el contenido sobre la carpeta del repositorio (sin borrar `.git`), haz Commit y Push con GitHub Desktop. URL: https://matiasmendoza0905-glitch.github.io/D-Salms/

## Cómo reemplazar una imagen (ejemplo: la misión)
1. Busca `DS-IMG-EMP-001` en `docs/GUIA_IMAGENES_DSALMS.md` o en la página «Recursos visuales».
2. Lee la escena y la medida (1200 × 800 px, 3:2).
3. Copia el prompt (botón «Copiar prompt» en la guía web) y genera la imagen.
4. Expórtala como WebP (también se acepta JPG o PNG con el mismo nombre).
5. Guárdala con el nombre exacto `empresa-mision-01.webp`.
6. Colócala en `img/empresa/`.
7. Abre la página Empresa y comprueba que aparece en «Misión».
8. Revisa el encuadre en el móvil.
9. Sube los cambios con GitHub Desktop.
Si ves «IMAGEN PENDIENTE», el nombre o la carpeta no coinciden con la guía.

## Lo que es simulación
La encuesta de cinco participantes, las marcas conceptuales A y B, las conversaciones y las fotografías A/B son ejemplos académicos identificados como tales en la página.
